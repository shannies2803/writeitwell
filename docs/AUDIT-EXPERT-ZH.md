# 华文部分专家审查报告（小学华文作文）

审查范围：zh-basics、zh-more1～4（全部逐课阅读），zh-banks / zh-wb1～15 / zh-x1～7 / zh-p1～2（抽查 45 组词语、约 120 个成语、70 道选择题，并用脚本做了全面检查），以及 400 篇范文（细读 47 篇：低年级 18、中年级 21、高年级 8；另读了课程里的约 25 篇示范文）。

## 一、总体评价与优点

1. **质量整体很高。** 语言自然规范，新加坡生活情境（组屋、小贩中心、巴刹、地铁、多元种族的名字和节日）用得自然，不生硬。
2. **准确性好（有脚本核查）。**
   - 拼音：672 条成语和闪卡拼音与字典逐字比对，没有发现真正的错误；只有 1 处轻声标注不够规范（已改）。多音字处理得很好，例如 千钧一发 fà、勤学好问 hào、一朝一夕 zhāo、不亦说乎 yuè、刚正不阿 ē。
   - 繁体字：47,298 个字符串全部用简繁转换检查，**一个繁体字也没有**。
   - 的、地、得：用正则扫描全部内容，除了“改错题”本来就故意写错的句子，没有发现误用。
   - 对话标点（提示语在前、在中间、在后三种格式）、顿号和逗号、分号、省略号、书名号，讲解都正确，例子也好。
   - 修辞分类、关联词分类、量词表、形近字口诀都正确、实用。
3. **教学设计扎实。** 中高年级的教学线很完整：审题 → 构思（故事山加六何法）→ 开头和结尾 → 分段 → 句子和句式 → 描写方法 → 高潮 → 详略 → 借景抒情 → 立意 → 考场策略 → 升格。“作文升格”“一步一步写好作文”“看懂老师的评语”三课特别好，能把方法教给学生，学生可以带走用在别的作文上。
4. **范文。** 400 篇的字数全部符合规格（低年级平均 237 字，中年级 420 字，高年级 642 字），标记数量也合适。情节真实，人物有缺点，也有犹豫和挣扎；结尾多数不说教，开头有变化。低年级的范文句子短、心情变化清楚，适合小二、小三。“点评”几乎每条都写出了可以带走的方法（例如“用动作写害怕”“首尾呼应”“把关键一秒拉长”），不是空泛的夸奖。

## 二、发现的问题

### A. 覆盖面上的缺口（最重要）
1. **没有给小一、小二的“看图写话”课。** 低年级的学习路线（engine 里的 PATHS.A）从“写作六步”“看图作文”开始，但这两课都是给中高年级的（讲故事山、高潮、伏笔），小一的孩子学不来。其实网站已经有一组很好的“低年级好词好句”（zh-chuxue，里面有看图写话四要素），可是它不在学习路线里，也没有配套的教学课。
2. **没有“写好一段话”的过渡课。** 华文薄弱的小三学生，卡在“会写句子，但不会把句子连成段、再连成篇”。现有的“分段与过渡”讲的是什么时候分段，没有讲一段话里面怎样组织（开头句、中间句、结尾句，段落写法，删掉跑题的句子）。
3. **没有“写人作文”的课。** 《我的好朋友》《我的妈妈》《我最敬佩的人》是常见题目，但网站里的课和 400 篇范文几乎都是记事作文，没有教“抓住一个特点，用事例来证明”。
4. 看图作文没有提到“最后一幅图是空白或画着问号，要自己想结局”的题型（我只用“有的题目”这种说法补上了，没有写死考试格式）。

### B. 准确性和用词
- “对比与衬托”里的“正衬”例子其实是**反衬**：别人都累得坐下休息，只有队长还在递水。
- 成语闪卡“七上八下”的释义写成了“像十五个吊桶打水一样”，这是歇后语里的说法，小学生看了会糊涂。
- 电邮改错题说“漏了日期”：电邮会自动显示日期，把日期当成必须写的格式要求，可能会误导学生。
- “热闹非凡”的“闹”标成了轻声。
- 词语宝库里有几处不妥：
  - 用“肚子圆得像个大西瓜”“皮肤黑得发亮，像抹了一层油”来比喻外貌，有取笑身材和肤色之嫌。
  - 例句里用了“小侄女”（小学生很少有侄女）。
  - “身体是革命的本钱”是中国大陆的政治口号式说法，不适合新加坡孩子。
  - 部首组里写“女字旁：和女性有关”“雨字头：和天气有关”，可是同一组里有“好、她”和“零、需、露”，标题和内容对不上。

### C. 年级与合理性
- “作文升格”里的《我学会了骑脚车》（修改前和修改后）标成了高年级，内容其实是中年级水平。
- 高年级范文《勇敢的一次》写学校游泳课上“五米高的跳台”，不太真实。
- 一道选择题用“秋天田野里的稻子”，不是新加坡孩子熟悉的情境。
- 限时写作（studio）不分年级，一律要求 300 字。可是低年级的学习路线也会带孩子进来，小一的孩子写不了 300 字。

### D. 范文的小问题
- 两个文件里有 61 处把逗号放进了 `<mark>` 标记里面（例如“像一根小刺，”），收进好词好句库以后，词语末尾会带一个逗号。
- 书信体范文《给巴士上那位安娣的信》把“称呼和问候”写在同一段，署名和日期也挤在一行。可是这篇的点评正好在教“注意称呼、问候、署名”，前后矛盾。
- 一些说法用得太多（400 篇里的出现次数）：“手心”57 篇，“心怦怦直跳”24 篇，“脸一下子红”18 篇，“眯成了一条缝”11 篇。这不算错，只是孩子背下来以后容易写得千篇一律。我没有大面积改动，建议以后新写范文时避开这些说法。

### E. 词语宝库是否好找
内容很丰富（2,098 个词组，17,672 个词条，570 个成语），但单元太多，而且互相重叠，最有用的内容反而不好找。例如：天气和景物有 3 个单元；好句、开头结尾、主题宝典、描写好句库有 4 个单元；情绪词又分散在 x1、x5 的扩充内容里。小一的孩子打开“成语宝库”或“歇后语”，看到的是“司马昭之心”“徐庶进曹营”“和尚打伞——无法无天”这样的条目，太深，也不合适。

## 四、我做不了的建议（主要是网站功能）

1. **学习路线（engine 的 PATHS）。**
   - 低年级（A）：建议改成 `zh-kantu → zh-chuxue → zh-picstories → zh-feelings → zh-actionwords → zh-reduplication → zh-measure → zh-dialogue → zh-punctuation → zh-chars → zh-ladders → zh-warmups → zh-models3 → zh-studio`。也就是去掉“写作六步”“看图作文”和“精彩开头”，这三课留到中年级再学。
   - 中年级（B）：在 zh-paragraphs 后面加 `zh-yiduan`，在 zh-describe 前面加 `zh-xieren`。
   - 高年级（C）：可以加 `zh-xieren`。
2. **图标（ICONMAP）。** 新的三个课还没有图标，建议加上：`kantu:"pictures", yiduan:"paragraph", xieren:"person"`。
3. **限时写作的字数要求按年级来定。** 现在所有人都是 300 字。建议低年级约 60 到 150 字（或者按句子数计算），中年级 300 字，高年级 500 字。
4. **词语宝库要分级，还要能搜索。** 给每个词组和成语加上年级标记（低、中、高），按孩子的年级只显示合适的内容。再加一个搜索框，并为每个年级做一份“精选 100 个好词好句”。歇后语和古文名句建议只给高年级看。
5. **范文库可以按题型筛选。** 题型包括看图作文、命题作文、写人、书信或日记、电邮；也可以按字数筛选。小一、小二特别需要大约 20 篇 60 到 150 字的看图写话短范文（现在只有新课里的 2 篇）。最好配上真正的图片，可以借用现有的 picsets 来做。
6. **合并互相重叠的单元。** 天气和景物的 3 个单元可以合成一个，好句、开头结尾这一类的 4 个单元也可以合成一个；现在有 37 个成语在不同单元里重复出现。可以在单元页面上加“相关单元”的链接，代替重复的内容。
7. **考试格式。** 网站对考试格式的说法比较笼统，这是对的。如果以后要加入 PSLE 的具体格式（实用文的类型、作文的选题方式、时间、分数），建议先对照教育部和考试局最新的考试说明再写。
